# Instructions for Claude

## Critical Communication Protocol

**ALWAYS after receiving a user message, ask yourself:**
- "Is this clear?"
- "Do I have any questions regarding this?"
- "How can the user make it 100% clear to me?"

This applies to **ALL work** including:
- Discussions
- Analysis
- Planning
- Implementation
- Explanations
- Bug fixes
- Feature requests
- Code reviews
- Any other task

**Before starting any work, clarify:**
1. Ambiguous requirements
2. Technology/library preferences
3. Architecture decisions
4. Expected behavior
5. Edge cases

**Better to ask and be certain than to assume and be wrong.**
